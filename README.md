# My RSB Order Robot - Level II Python

Orders robots from RobotSpareBin Industries Inc.
- Downloads orders.csv, fills form, previews, submits with retry
- Saves receipt PDF + robot screenshot, embeds screenshot to PDF
- Zips receipts to output/receipts.zip

## Run
1. Open in VS Code with Sema4.ai extension
2. `Sema4.ai: Run Task Package`

No manual setup needed. Env from `conda.yaml`.
